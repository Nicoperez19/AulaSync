# Bitácora semanal

**Proyecto:** AulaSync  
**Semana:** 21 al 27 de septiembre de 2026  
**Período de trabajo registrado:** 23 al 26 de septiembre de 2026

## Objetivo

Preparar el módulo de soporte de AulaSync para contar con un rol y permisos propios, facilitar la revisión de tickets por sede y habilitar un dashboard de soporte antes de activar los cambios de roles en la base de datos.

## Actividades realizadas

- Se revisó la configuración existente de roles, permisos, rutas y sistema de tickets.
- Se agregó al seeder el rol **Soporte** y el permiso `gestionar tickets de soporte`, asignado exclusivamente a ese rol.
- Se integró el rol/per permiso de Soporte con las funciones de atención de tickets y se preparó el filtrado de tickets por sede.
- Se creó la vista del dashboard de soporte, con tarjetas de resumen, filtro por sede y listado de tickets abiertos o en proceso.
- Se agregó la ruta `/soporte/dashboard` y el acceso desde la barra lateral.
- Para poder revisar el dashboard antes de ejecutar el seeder, se habilitó una vista previa para usuarios autenticados. Quienes aún no sean personal de soporte solo pueden ver sus propios tickets.
- Se ajustaron las comprobaciones de roles para evitar errores cuando un rol todavía no existe en la base de datos.
- Se confirmó que la ruta del dashboard está registrada y se revisó la sintaxis PHP de los archivos modificados.
- Se confirmó con el usuario que pudo abrir y visualizar el dashboard.

## Resultado

El dashboard visual está disponible en `/soporte/dashboard`. La vista previa funciona sin ejecutar el seeder; el alcance de datos depende del usuario autenticado y se limita a sus propios tickets si aún no tiene un rol de soporte reconocido.

## Pendientes

- Ejecutar `php artisan db:seed --class=RoleSeeder` cuando se decida activar el rol y el permiso en la base de datos.
- Asignar el rol **Soporte** a los usuarios que deban atender tickets.
- Revisar la matriz final de permisos del rol antes de usarlo en operación.
- No se ejecutó la suite de pruebas durante este período.
